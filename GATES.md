## Remediated Vulnerability Catalog (`G1`–`G6`)

| ID | Component | Severity | Root Cause | In-Place C11 Remediation |
|---|---|---|---|---|
| `VULN-KERNEL-001` | `policy.h:34-39` | Low (Defense-in-Depth) | `__builtin_bswap16(p->protocol)` truncated upper 16 bits of 32-bit `skb->protocol` on little-endian architectures. | Added `(p->protocol & ~0xffffu)` upper-bit guard before `__builtin_bswap16((unsigned short)p->protocol)` and added regression test in `tests/test_policy.c:116`. |
| `VULN-KERNEL-003` | `policy.h:69-76` | Low (Defense-in-Depth) | TCP options (`hdr > 20`) were bounds-checked against `transport` without reading the final option byte via `CSG_READ`. | Added `(hdr > 20 && CSG_READ(p, 34 + hdr - 1, &opt_end, 1))` tail readability probe. |
| `VULN-DETECT-001` | `detect_policy.h:5-12` | Medium | `csg_suspicious()` did not reject `network_header == 0xffff` (unset sentinel) or 16-bit `network_header + ihl` wrap-around when called directly. | Added `network_header <= 0xffffu - ihl && start <= 0xffffu` inside `csg_suspicious()` and 7 boundary assertions in `tests/test_policy.c:146-152`. |
| `VULN-DETECT-002` | `csumguard_detect.bpf.c:21-60` | Low | `BPF_CORE_READ_BITFIELD_PROBED(skb, ip_summed)` folded kernel read errors into `0` instead of `DET_READ_ERROR`, and `nh + ihl` 16-bit wrap-around was unguarded before `csg_suspicious`. | Added `!skb` guard, explicit `bpf_probe_read_kernel` on the `ip_summed` byte offset, `nh > 0xffffu - ihl` check under `DET_BAD_HEADER`, and tail byte probe `head + nh + ihl - 1`. |
| `VULN-LOADER-001` | `loader.c:259-315` | High | Post-attach error handling could call `bpf_tc_hook_destroy(&hook)` even if the interface concurrently transitioned `UP`, stripping an active guard from a live interface; conversely, `read_stats` failure left the hook attached while exiting `1`. | Tracked `hook_created` and `filter_attached`; on `fail:`, `bpf_tc_hook_destroy(&hook)` is called only if `if_nametoindex(argv[2]) == idx && iface_down(argv[2]) == 1`, preserving the guard fail-closed if the interface came `UP`. |
| `VULN-LOADER-002` | `loader.c:67-162` | Medium | `verified_object()` checked leaf `fstat()` without verifying ancestor directories from `/`, `st_nlink == 1`, or post-read EOF/metadata stability. | Implemented `open_verified_path()` walking from `/` with `openat(..., O_RDONLY \| O_CLOEXEC \| O_DIRECTORY \| O_NOFOLLOW)`, enforcing `st_uid == 0`, `(st_mode & 022) == 0`, `st_nlink == 1`, and post-read EOF + unchanged `fstat`. |
| `VULN-LOADER-003` | `loader.c:19-65, 197-225` | Low | `REASONS` was hardcoded separately from `policy.h`, `iface_down()` lacked a self-contained `IFNAMSIZ` guard, counter summation could wrap `uint64_t`, and JSON was printed unbuffered before `read_stats` completed. | Included `policy.h` with `_Static_assert`, added `strlen(name) >= IFNAMSIZ` check in `iface_down()`, saturating `uint64_t` addition in `read_stats()`, and atomic buffered output in `emit_json()`. |
| `VULN-LAUNCH-001` | `launch.c:253-264, 1061-1238` | High | Asynchronous `SIGINT`/`SIGTERM`/`SIGHUP` arriving during quarantine teardown could interrupt `disconnect()` (`ip link set down`) or skip emitting `denied_or_quarantined`. | Blocked asynchronous signals in `csg_receipt_worker` via `pthread_sigmask`, checked `g_stop_signal` before every pre-launch step, and masked `SIGINT`/`SIGTERM`/`SIGHUP` across all threads upon entering `contain:`. |
| `VULN-LAUNCH-002` | `launch.c:1278-1290` | Medium | Normal VMM exit (`returncode == 0`) ignored `cleanup_disconnect_failed` and returned exit status `0` while leaving the TAP interface `UP`. | Forced `exit_code = 1` whenever `csg_disconnect_iface()` fails during normal-exit cleanup. |
| `VULN-LAUNCH-003` | `launch.c:1244-1258` | Medium | Process-group `SIGKILL` was gated on session leader `poll() == None`, leaving same-PGID child processes suspended in `SIGSTOP` if the session leader exited early. | Unconditionally sends `kill(-vmm_pid, SIGSTOP)` -> `csg_disconnect_iface()` -> `kill(-vmm_pid, SIGKILL)` -> bounded `wait_vmm()` whenever `vmm_pid > 0`. |
| `VULN-LAUNCH-004` | `launch.c:454-490` | Medium | `ReceiptWriter.close()` used non-blocking `put_nowait(None)` and dropped the close sentinel when all 64 ring-buffer slots were occupied. | `csg_receipt_close()` waits on `not_full` via `pthread_cond_timedwait` up to the `200ms` deadline before setting `closing = true` and waiting on `done_cond`. |
| `VULN-LAUNCH-005` | `launch_policy.h:289-308, 681-740` | Low | Identity comparison accepted empty or missing `interface` fields if both dictionaries lacked valid strings, and accepted boolean `true`/`false` for integer IDs. | `csg_valid_identity()` and `csg_parse_identity_json()` enforce non-empty `csg_valid_ifname(id->interface)` and strictly positive `uint32_t`/`uint64_t` integers for `ifindex`, `netns_inode`, and `prog_id`. |
| `VULN-LAUNCH-006` | `launch_policy.h:336-425`, `launch.c:68-228, 397-446` | Medium | Path-string `stat()` TOCTOU before `open()`, unchained JSONL receipts, and vector-state collapse between missing status observation (`UNKNOWN`) and identity mismatch (`ANTI`). | Implemented descriptor-chained `csg_open_trusted_file_at()` / `csg_open_trusted_receipt_at()`, FIPS 180-4 SHA-256 hash-chained receipts (`seq`, `prev_sha256`, `entry_sha256`), and 6D vector state $\langle P, V, C, E, L, \tau \rangle$. |
| `VULN-LAUNCH-007` | `launch.c:231-365, 454-490` | High (Caught by ASan) | Stack-allocated `struct csg_receipt_writer` in `csg_launch_run()` suffered stack-use-after-return when `csg_receipt_close()` detached a stalled writer thread on timeout. | Changed `csg_receipt_create()` to heap-allocate `struct csg_receipt_writer` with mutex-synchronized `detached` ownership transfer so a timed-out detached worker thread safely frees its own state upon completion. |
| `VULN-BUILD-001..003` & `VULN-TESTBED-001..002` | `Makefile:1-44`, `testbed.sh:1-86`, `tests/send_frame.c:1-257` | Medium | `Makefile` omitted `csumguard_launch` and `send_frame`, left empty `vmlinux.h.tmp` on `bpftool` failure, and `testbed.sh` / `send_frame` relied on interpreted scripts. | Hardened `Makefile`, replaced `send_frame` with C11 `tests/send_frame.c`, and rewrote `testbed.sh` in pure bash with capability bitmask checks and `/dev/urandom` token validation. |
