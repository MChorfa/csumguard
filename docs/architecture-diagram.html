csumguard Architecture & Isolation Boundary

TC Ingress Filter
Restricted L2/L3/L4 admission parser runs directly on the TAP interface clsact qdisc. Drops fragmentation, options, GSO, and VLANs before the host network stack is reached.
Supervised Lifecycle
csumguard_launch drops privileges, launches the VMM in an isolated process group, and polls attachment identity every 200ms across a 6D state vector.
Fail-Closed Quarantine
On filter loss or attachment drift, signals are masked and the VM is paused via SIGSTOP, the link is set DOWN, and the process group is terminated via SIGKILL.
