TC Ingress Filter · Classification Logic

csumguard Packet Admission Flow

Strict IPv4 & ARP Profile
Only standard IPv4 packets without options (IHL == 5) and unfragmented payloads (MF == 0, offset == 0) are permitted. VLAN tags and non-standard EtherTypes are immediately dropped.
Port & Length Sanity
TCP source and destination ports must be non-zero. UDP destination ports must be non-zero. Declared IP and transport lengths must match actual packet byte lengths.
Reason Telemetry
Every dropped frame updates an exact per-CPU reason bucket in csg_stats, enabling operators to audit drops without packet capture or performance penalty.
